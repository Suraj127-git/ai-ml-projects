```bash
# Read the master guide
open MASTER_GUIDE.md

# Or get quick overview
open QUICK_REFERENCE.md
```

### Step 2: Set Up Your Environment (10 minutes)

```bash
# Prerequisites
- Python 3.8+
- Docker (optional)
- Git

# Clone repository
git clone <repo-url>
cd ai-ml-projects
```

### Step 3: Start Your First Project (2-10 hours)

```bash
# For complete beginners

cat DOCUMENTATION.md  # Read comprehensive guide

# Install dependencies
pip install -r requirements.txt

# Start API
uvicorn app.main:app --reload

# Test API
curl http://localhost:8000/docs
```
